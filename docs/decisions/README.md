# Decisões arquiteturais (ADRs)

ADRs registram decisões arquiteturais significativas e seus motivos. Use nomes sequenciais no formato `ADR-001-nome-da-decisao.md`.

Cada registro deve incluir status, contexto, problema, decisão, alternativas consideradas e consequências. Estados sugeridos: `Proposed`, `Accepted`, `Superseded` ou `Deprecated`.

Não há ADRs históricos neste repositório. A arquitetura atual foi documentada em [`../architecture/overview.md`](../architecture/overview.md), mas não se deve inferir razões históricas a partir apenas da implementação. Crie um ADR quando uma decisão significativa for efetivamente tomada; não use ADR para registrar como decisão algo que é apenas descrição do estado existente.
